# 📖 Overview

This project presents an intelligent real-time anomaly detection system for IoT sensor streams using Machine Learning.

The system continuously receives sensor data, preprocesses it, extracts meaningful features, predicts anomalies using a trained ML model, stores alerts in a database, and provides an interactive dashboard with an AI-powered assistant.

- 🚀 Real-Time Anomaly Detection
- 📈 Live Dashboard
- 🤖 AI Assistant
- ⚡ Stream Analytics
- 📊 Prediction Visualization
